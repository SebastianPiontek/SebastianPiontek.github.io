Über den Entwickler

     
       

Handarbeit aus Duisburg

       

Hinter Aura Applications steht keine namenlose Software-Agentur, sondern unabhängige, leidenschaftliche Entwicklungsarbeit. Jede Zeile Quellcode wird mit höchstem Anspruch an Design, Geschwindigkeit und Datenschutz geschrieben.

       

Das Ziel ist es, verlässliche Werkzeuge für das Smartphone zu schaffen, die auf unnötigen Ballast verzichten und einfach funktionieren.

     
   
       
     

Häufig gestellte Fragen

     
                
          Warum gibt es bei Aura Applications keine Abonnements?          

Gute Software sollte ein verlässlicher Gebrauchsgegenstand sein. Wir setzen auf das klassische Kaufmodell: Einmal zahlen, unbegrenzt nutzen.

       
       
          Benötigen die Apps eine aktive Internetverbindung?          

Nein. Alle Hauptfunktionen laufen vollständig lokal auf deinem Smartphone. Dadurch funktionieren die Apps auch im Flugmodus vollkommen problemlos.

       
       
          Werden meine Daten irgendwo abgespeichert?          

Nein. Es gibt keine externe Datenerfassung oder Tracker-Einbindung. Sämtliche Eingaben bleiben absolut privat auf deinem Gerät.
