Häufig gestellte Fragen (FAQ)

Werden meine JSON-Daten, Tokens oder Passwörter an Server übertragen?

Nein, unter keinen Umständen. Sämtliche Validierungen, Base64-Kodierungen, Hash-Berechnungen und JWT-Dekodierungen finden ausschließlich lokal auf deinem Android-Gerät über native Web-Crypto-APIs statt. Es besteht keinerlei Server-Anbindung.

Wie funktioniert die magische JSON-Auto-Reparatur?

Häufig scheitert JSON an typischen Fehlern: Kommentare (// oder /* */), einfache Anführungszeichen, vergessene Anführungszeichen um Objektschlüssel oder überflüssige Kommas vor schließenden Klammern. Die Auto-Reparatur erkennt diese Syntaxfehler und bereinigt sie mit einem Fingertipp zu gültigem JSON.

Kann die App auch sehr große Dateien hashen oder kodieren?

Ja. Für Prüfsummen (SHA/MD5) verwendet die App ein speicherschonendes Chunking-Verfahren in 2-MB-Blöcken, sodass selbst große Dateien ohne RAM-Überlauf verarbeitet werden. Data-URIs über 500 KB werden automatisch als Datei bereitgestellt, um Abstürze der Android-Zwischenablage zu verhindern.

Welche Programmiersprachen unterstützt der Code-Compiler?

Der Compiler erzeugt typisierte Schnittstellen und Modelle für TypeScript (Interfaces), C# (Klassen mit JsonPropertyName), Rust (Structs mit Serde-Annotationen), Python (strukturierte Dicts mit JSON-Export), JavaScript (ESM) sowie gebrauchsfertige cURL-Befehle für die Kommandozeile.
