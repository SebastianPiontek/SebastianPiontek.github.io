Datenschutzerklärung (Privacy Policy)

Der Schutz Deiner Daten steht bei Aura Applications an erster Stelle.

1. On-Device Datenverarbeitung

Alle Kernfunktionen unserer Apps verarbeiten Eingaben und Daten ausschließlich lokal auf Deinem Endgerät (über localStorage und IndexedDB). Es werden keine Inhaltsdaten an externe Server gesendet.

2. Drittanbieter-Dienste

Zur Refinanzierung nutzen wir Werbeeinblendungen via Google AdMob sowie für In-App-Käufe den Dienst RevenueCat. Diese Dienste können anonymisierte technische Identifikatoren zur Bereitstellung der Funktionen verarbeiten.
